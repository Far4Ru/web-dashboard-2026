# Учебный дашборд ПРОМТЕХДИЗАЙН

Учебное одностраничное приложение на чистом JavaScript (ES6 modules). Виджеты можно добавлять, удалять, сворачивать, менять местами и изменять их размер. Раскладка, тема, имя и выбранное расписание сохраняются в `localStorage`.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

Сборка создаётся в папке `docs/`. Это сгенерированные файлы, поэтому они не хранятся в Git.

Опубликованная версия: [web-disign-dashboard-2026.vercel.app](https://web-disign-dashboard-2026.vercel.app).

## Управление

- Перетаскивание: зажмите заголовок карточки и перенесите её.
- Размер: потяните маркер в правом нижнем углу карточки.
- Клавиатура: сфокусируйте карточку; `Alt + ←/→` меняет позицию, `Alt + ↑/↓` меняет размер.
- Кнопка с шестерёнкой открывает настройки: управление виджетами и очистку сохранённых данных.

## Архитектура

- `UIComponent` — абстрактный базовый класс: общий DOM-каркас, сворачивание, подписки и очистка ресурсов.
- `GroupSelectorWidget` выбирает группу или преподавателя с дополнительными фильтрами каталога.
- `StatsWidget`, `CampusMapWidget`, `TodayScheduleWidget`, `RoomsWidget`, `MonthLoadWidget` — независимые наследники со своим состоянием и API-запросами.
- `SutdApi` — запросы к API расписания и функции даты.
- `DataCache` — общий кэш ответов в IndexedDB с защитой от повторных одновременных запросов.
- `UniversityWorker` и `UniversityData` — фоновая загрузка, сохранение и фильтрация расписаний всех групп.
- `RequestArchive` — восстановление каталогов и расписаний из файлов `requests/`, когда API недоступен.
- `api/university.js` — Vercel Function, которая читает официальный API СПбГУПТД частями по 48 групп и кэширует ответы на CDN.
- `Dashboard` — коллекция виджетов, фабрика компонентов, Drag&Drop, resize и сохранение раскладки.
- `main.js` — инициализация страницы, модальные окна, тема и уведомления.

## Источник данных

Расписание и каталоги загружаются из официального `schedule.sutd.ru/api` через правила `vercel.json`. Общие показатели и режимы «Все занятия» рассчитываются из расписаний всех групп. Первая загрузка этих режимов может занять время, пока функция собирает 28 частей. В браузере части хранятся в IndexedDB шесть часов, отдельные расписания — час, каталоги — сутки. Повторные запросы в пределах вкладки объединяются, а фоновый Worker заранее заполняет кэш текущего месяца. При сбое API данные берутся из свежего кэша, затем из сохранённого архива.

Архив `requests/` содержит каталоги групп, преподавателей и институтов, а также все 28 ответов агрегатора за октябрь 2026 года: 1323 группы и 37 388 записей занятий текущего семестра (1 сентября — 27 декабря 2026 года). Он включается в production-сборку. Обновить архив, пока API доступен:

```bash
node scripts/archive-requests.mjs 2026-10 --refresh
```

Архив хранит данные, которые использует дашборд; он не заменяет динамические картографические тайлы и будущие изменения расписания после даты сохранения.

Свободными считаются аудитории, встречающиеся в расписании текущего семестра и не занятые в выбранное время. Полного реестра помещений официальный API не предоставляет.

Добавление нового типа виджета: унаследуйте класс от `UIComponent` и зарегистрируйте его в таблице `types` класса `Dashboard`.

## API и состояния

- Расписание: [СПбГУПТД](https://schedule.sutd.ru/) — каталоги групп и преподавателей, недельные расписания выбранной сущности. В разработке запросы проходят через proxy Vite, а для публикации добавлен rewrite в `vercel.json`.
- Карта: [OpenStreetMap](https://www.openstreetmap.org/) и Nominatim — картографическая подложка и определение координат учебных корпусов.
- Цитаты: [citaty.info](https://citaty.info/selection/citaty-stethema) — HTML страницы загружается при старте, тексты безопасно извлекаются через `DOMParser`/`textContent`, перемешиваются и показываются без повторов в пределах цикла.

Виджеты показывают загрузку, пустой результат, ошибку и успешное состояние. Ответы API вставляются через `textContent`; динамические данные не передаются в `innerHTML`.

## Ограничения

- Для первой загрузки свежих данных нужен интернет. Если API недоступен, приложение использует кэш или архив текущего семестра.
- Официальный API не предоставляет полный реестр помещений. Свободными считаются аудитории, которые встречаются в сохранённых расписаниях семестра.
- Атрибуция OpenStreetMap остаётся видимой в компактном виде согласно условиям использования картографических тайлов.
- Изменение размера — дискретное: одна или две колонки. На мобильном экране все карточки занимают одну колонку.
- Таймер сохраняет оставшееся время, но не продолжает отсчёт при закрытой вкладке.

## Использование ИИ

ИИ использовался для первичного проектирования интерфейса, генерации черновой структуры классов и проверки соответствия критериям задания. Итоговая структура, поведение Drag&Drop, доступность, обработка API-состояний и визуальная система были собраны и согласованы как единое решение.
